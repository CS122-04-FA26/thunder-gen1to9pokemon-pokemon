# Instructions on how to get the data

We use this dataset from Kaggle:
https://www.kaggle.com/datasets/brdata/complete-pokemon-dataset-gen-iiv

---

Download

1. Make a Kaggle account at https://www.kaggle.com/account/login
2. Go to the dataset page:
   https://www.kaggle.com/datasets/brdata/complete-pokemon-dataset-gen-iiv
3. Click the Download button (top right)
4. Unzip the .zip file
5. Yay data
